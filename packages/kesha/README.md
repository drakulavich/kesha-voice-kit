# kesha

The short name for [`@drakulavich/kesha-voice-kit`](https://www.npmjs.com/package/@drakulavich/kesha-voice-kit). It installs the same `kesha` command, at the same version.

```bash
bun add -g kesha
kesha install
kesha audio.ogg
```

Documentation: https://github.com/drakulavich/kesha-voice-kit
